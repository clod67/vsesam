# VSËSAM

**Игровой движок на Rust + собственный эзотерический язык `nanch`, AI-агенты и логин с сессиями, которые встраиваются прямо в движок.**

> _A from-scratch Rust game engine driven by the `nanch` scripting language —
> Chinese + Arabic keywords, `؛` statement terminators — with built-in AI agents
> and a login layer whose sessions get grabbed and embedded straight into the
> running world._

Ноль сторонних зависимостей. Только `std`. Язык, ECS, рендер, AI-мозги,
хеширование паролей (SHA-256) и хранилище сессий — всё написано руками.

## Быстрый старт

```sh
cargo build --release

# аккаунт + вход (токен запоминается)
./target/release/vsesam register klod 1337
./target/release/vsesam login    klod 1337

# прогнать встроенную арену с AI-агентами
./target/release/vsesam demo --ticks 40

# или свой скрипт на nanch
./target/release/vsesam run  scripts/arena.nanch --ticks 40
./target/release/vsesam play scripts/agents.nanch        # анимированно
./target/release/vsesam repl                              # интерактивно
```

Запусти арену под логином несколько раз — номер волны **сохраняется в сессию**
и орда растёт с каждым прогоном. Это и есть «сессии встраиваются в движок».

## Язык `nanch`

`nanch` — нарочито чужеродный язык. Выражения завершаются арабской точкой с
запятой `؛` (U+061B), комментарии начинаются с арабского `؟` (U+061F), а
зарезервированные слова — иероглифы (плюс один арабский глагол для цикла).
Всё остальное (`喊`, `生`, `脑` …) — обычные идентификаторы, которые в рантайме
резолвятся в нативные функции движка.

### Ключевые слова

| nanch   | значение            | пример                                  |
|---------|---------------------|-----------------------------------------|
| `设`    | объявить переменную | `设 x = 5؛`                             |
| `函`    | функция             | `函 сумма(a, b) { 回 a + b؛ }`          |
| `回`    | вернуть             | `回 x؛`                                 |
| `如果`  | if                  | `如果 (x > 0) { … }`                    |
| `否则`  | else                | `… 否则 { … }`                          |
| `طالما` | while (араб.)       | `طالما (i < 10) { i = i + 1؛ }`         |
| `真`    | true                | `设 жив = 真؛`                          |
| `假`    | false               | `设 мёртв = 假؛`                        |
| `空`    | nil                 | `如果 (цель == 空) { … }`               |

Операторы — обычные: `+ - * / %`, `== != < > <= >=`, `&& || !`, присваивание `=`.
Строки в `"…"` (с `\n`, `\t`, `\"`), числа — `f64`. Идентификаторы могут быть на
любом языке (латиница, кириллица, 中文…).

### Нативные функции (мост `nanch` ↔ движок)

**Вывод/конвертация:** `喊(…)` печать · `字(v)` в строку · `数值(s)` в число

**Спавн/жизнь:** `生(вид, x, y)` → id · `代理(вид, x, y, мозг)` агент+мозг · `毁(id)`

**Движение:** `动(id, dx, dy)` — задать смещение на этот тик

**Статы:** `血(id)` hp · `满血(id)` макс · `治(id, n)` лечить · `伤(id, n)` ранить →
убит? · `阵(id)` фракция · `设阵(id, t)` · `名(id)` вид · `标(id[, текст])` метка ·
`活(id)` жив?

**Запросы:** `近(id)` ближайший враг · `谁(id)` ближайший кто угодно ·
`距(a, b)` дистанция · `横(id)`/`纵(id)` координаты x/y · `数量()` всего ·
`敌数()`/`友数()` враги/друзья · `时()` текущий тик

**AI:** `脑(id, поведение)` задать мозг · `脑(id)` узнать текущий мозг

**Математика:** `数([lo,] hi)` случайное (детерминир.) · `底` floor · `绝` abs ·
`根` sqrt · `最小`/`最大`

**Сессия (встраивается в движок):** `记(ключ, знач)` записать · `取(ключ)` прочитать
· `我()` имя игрока

### Виды сущностей (`生`)

`player`/`玩家` `@` · `agent`/`代理` `A` · `goblin`/`哥布林` `g` · `orc`/`兽人` `O` ·
`slime`/`史莱姆` `s` · `wall`/`墙` `#` · `gold`/`金` `$`. Фракции: `0` — игрок/союзники,
`1` — монстры, `-1` — нейтралы (золото, стены — в бою не участвуют).

### Пример

```nanch
؟ знак разницы: куда шагнуть, чтобы сблизиться
函 знак(a, b) {
  如果 (b > a) { 回 1؛ }
  如果 (b < a) { 回 -1؛ }
  回 0؛
}

؟ собственный мозг-агент: движок зовёт его каждый тик с id сущности
函 охотник(id) {
  设 цель = 近(id)؛                 ؟ ближайший враг
  如果 (цель == 空) { 回؛ }
  动(id, знак(横(id), 横(цель)), знак(纵(id), 纵(цель)))؛
}

设 a = 代理("agent", 10, 5, охотник)؛   ؟ агент с мозгом-функцией
生("goblin", 40, 15)؛                     ؟ жертва
```

## Движок

- **ECS-lite** (`src/engine/world.rs`): сущности — плоские записи компонентов
  (позиция, скорость, здоровье, спрайт, фракция, боёвка, мозг). Спавн из
  прототипов, свободный список переиспользует id.
- **Системы, каждый тик**: глобальный хук `每拍` → мозги-агенты → встроенные
  поведения → интеграция движения → разрешение боя → уборка трупов.
- **Бой**: каждый вооружённый боец раз в тик бьёт ближайшего врага в радиусе.
- **Рендер** (`src/engine/render.rs`): ASCII-грид в рамке; работает в любом
  терминале и headless, кадр за кадром. Для `play` — очистка экрана ANSI.

## AI-агенты

Два пути — и оба это «AI-агенты, встроенные в движок»:

1. **Встроенные мозги** (`src/ai/mod.rs`): `idle`, `wander`, `seek`, `flee`,
   `patrol`, `hunt`, и флагман **`think`** — утилитарный AI: ранен → отступает,
   враг в упор → дерётся, враг виден → догоняет, иначе бродит.
   ```nanch
   脑(id, "think")؛
   ```
2. **Мозги на `nanch`**: любая функция `f(id)`, назначенная через `脑`/`代理`,
   вызывается движком каждый тик — это полноценный автономный агент, чья логика
   написана на самом языке.
   ```nanch
   脑(id, моя_функция)؛
   ```

## Логин и сессии, встроенные в движок

`src/auth/` — аккаунты и сессии без единой зависимости:

- Пароли: солёный **SHA-256** (своя реализация, `src/auth/sha256.rs`) с 4096
  раундами усиления.
- Токен сессии выводится **детерминированно** из аккаунта, поэтому повторный
  вход переподключает тебя к **тому же** постоянному хранилищу ключ-значение.
- Это хранилище доступно из `nanch` через `记`/`取`. Так состояние игрока
  (счёт, инвентарь, флаги, номер волны) **захватывается и встраивается прямо в
  работающий движок** и переживает перезапуски.

```nanch
设 wave = 数值(取("wave"))؛        ؟ прочитать из сессии
如果 (wave == 空) { wave = 1؛ }
记("wave", wave + 1)؛              ؟ записать обратно — сохранится на выходе
```

Гостевая сессия (`--as guest` или без входа) не пишется на диск.

## Команды CLI

```
vsesam register <user> <pass>     создать аккаунт
vsesam login    <user> <pass>     войти (печатает + запоминает токен)
vsesam logout                     забыть текущую сессию
vsesam whoami   [--as <token>]    показать сессию и её ключи
vsesam run  <script> [opts]       прогнать сцену, печатать кадры
vsesam play <script> [opts]       анимированный прогон
vsesam demo [opts]                встроенная арена
vsesam repl [--as <token>]        интерактивный nanch
```

Опции `run`/`play`/`demo`: `--ticks N` · `--size WxH` · `--as <token>` · `--play`.

В REPL: `:тик` — шаг симуляции, `:кадр` — отрисовать, `:сохр` — сохранить сессию,
`:выход`.

## Структура

```
src/
  main.rs            CLI: аккаунты, run/play/demo, REPL
  nanch/             язык nanch
    token.rs · lexer.rs · ast.rs · parser.rs · value.rs
    interp.rs        интерпретатор + нативы + игровой тик (мост к движку)
  engine/
    world.rs         ECS, прототипы, движение, бой
    render.rs        ASCII-рендер
  ai/mod.rs          встроенные поведения AI-агентов
  auth/
    mod.rs           аккаунты, сессии, встраивание состояния
    sha256.rs        SHA-256 (std-only)
scripts/
  arena.nanch        флагманская демка (встроена в бинарник)
  agents.nanch       витрина кастомных мозгов + персистентной сессии
  hello.nanch        минимальный пример
```
